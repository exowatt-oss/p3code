# Pets

Romeo is a small animated cat inside the P3 Code window. He reacts to the open
thread: working while an agent runs, waiting when it needs approval or an answer,
celebrating a new completion, and reacting to errors. All P3 providers use the same
activity indicators, including Codex and Phi, locally and over remote connections.
When you leave the thread, he returns to idle.

Open **Settings → Customize → Pets** to:

- Enable or disable the pet.
- Adjust size and cursor curiosity.
- Import another `.t3pet` package, select it, or remove an imported pet.

Drag the pet to move him. You can also focus him and use the arrow keys. Hover or
click to interact. Only the pet itself intercepts clicks; the rest of the workspace
stays usable. Animations pause in hidden windows and respect reduced motion.

Pets and preferences are saved on this device and persist across P3 updates.
Each browser profile/origin has its own settings. They are not synced to your
remote server. Clearing this app's browser storage removes them. The native mobile
app does not display pets; the web and desktop clients do.
