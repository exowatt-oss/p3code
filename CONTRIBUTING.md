# Contributing to P3 Code

P3 Code is an independent MIT fork of [T3 Code](https://github.com/pingdotgg/t3code). Please file P3-specific bugs and proposals at [exowatt-oss/p3code](https://github.com/exowatt-oss/p3code/issues); upstream T3 Code issues should go to the upstream project. This fork is not endorsed by T3 Tools Inc.

Discuss substantial features with the fork maintainers before writing code. Focus each pull request on one problem; include the relevant tests and describe how you verified the change. See the [development guide](docs/operations/development.md) and [repository instructions](AGENTS.md) for the workspace's conventions. Never include service credentials, personal data or Exowatt internal material in an issue or patch.

Sign off every commit using `git commit -s` to certify the [Developer Certificate of Origin](https://developercertificate.org/). Contributions to this fork remain under the MIT license, preserving upstream notices and Exowatt attribution for modifications. Report security vulnerabilities [privately](.github/SECURITY.md), not in a public issue.
